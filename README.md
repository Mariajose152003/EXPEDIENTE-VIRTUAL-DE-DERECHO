# Expediente Virtual de Derecho

Aplicacion web estatica para consultar y administrar expedientes de demostracion.
El sitio se publica con GitHub Pages mediante el flujo de trabajo incluido.

El archivo `data/expedientes.json` se mantiene vacio en esta version publica.
No agregues expedientes reales, datos personales ni documentos PDF al repositorio.
Los documentos locales deben mantenerse fuera del control de versiones.

La aplicacion no incluye un servidor ni una base de datos compartida; los datos
creados desde el navegador se guardan localmente en ese navegador.
